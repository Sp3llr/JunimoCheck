# Segurança

## Relatando uma vulnerabilidade

Não publique vulnerabilidades que possam expor contas, fazendas ou dados em uma issue pública.

Use o recurso **Report a vulnerability** da aba Security do GitHub. Inclua:

- descrição do problema;
- passos para reproduzir;
- impacto esperado;
- sugestão de correção, se houver.

Nunca envie senhas, tokens, cookies, chaves privadas ou dados reais de usuários.

## Escopo

São especialmente importantes falhas relacionadas a autenticação, políticas RLS, convites, remoção de integrantes, upload de logos e acesso entre fazendas.
