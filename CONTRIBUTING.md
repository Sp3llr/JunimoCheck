# Contribuindo com o JunimoCheck

Obrigado por querer melhorar o projeto.

## Antes de começar

1. Procure uma issue existente sobre a mudança.
2. Para alterações maiores, abra uma issue explicando a proposta.
3. Não envie chaves, senhas, dados pessoais ou arquivos `.env`.
4. Evite adicionar novos assets protegidos por direitos autorais.

## Desenvolvimento

```bash
npm install
npm run dev
```

Antes de enviar sua alteração:

```bash
npm run lint
npm run build
```

## Pull requests

- Use um título direto e descritivo.
- Explique o problema e a solução.
- Inclua capturas de tela quando houver mudança visual.
- Mantenha cada pull request focado em um único objetivo.
- Confirme que o site continua funcionando em computador e celular.

Ao contribuir, você concorda em respeitar o [Código de Conduta](CODE_OF_CONDUCT.md).
